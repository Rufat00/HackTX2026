# Composition boundary

The default provider is a deterministic fixture, requiring no credentials. `AI_COMPOSITION_PROVIDER=openai`, server-only `OPENAI_API_KEY` and `AI_COMPOSITION_MODEL=gpt-6.1-sol` opt into the real adapter. The requested model's official documentation lists Responses, image inputs and structured outputs. Account availability is a separate requirement: `pnpm ai:check` first retrieves the exact model for that account, then makes an explicitly paid text fixture analysis. No live call is made by normal tests or startup.

The adapter uses the Responses API, strict Zod structured outputs, optional low-resolution image inputs, no tools, no stored response, and untrusted-data instructions. It validates known IDs, a complete unique partition, group IDs, bounded labels, canonical unique related pairs and at most three links per item. It rejects unsupported confidence values instead of presenting them as calibrated probabilities. Refusal, incomplete output, invalid data and timeouts trigger one retry, then a contributor-based deterministic fallback. At most five groups are returned; when more than five contributors exist, excess contributors share a neutral final group. Tiny boards use one group.

Each attempt has a 20-second budget; total analysis has a 45-second deadline. The SDK has retries disabled so retries cannot escape this policy. An outer timer also bounds misbehaving adapters. Metadata includes model, promptVersion, schemaVersion, inputContentRevision, fallbackReason and the visible label `Basic grouping used`. Tests inject fixtures and never make paid calls. The memory workflow persists a PROCESSING BoardLayout with its input snapshot/revision before calling the provider. It records this metadata and deterministic contributor-constellation geometry when the analysis becomes READY, and rejects results if content changed during the external work. The authenticated compose endpoint is owner-only.

AI proposes groups and semantic pairs. It never positions cards, animates backgrounds, identifies faces or confirms attendance. Geometry and palette interpolation now run in deterministic application code, independently of model output. Explicit tags and reviewed suggestions will remain distinct.
