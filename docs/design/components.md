# Native component catalog

All components use the semantic theme from `design/tokens.json`, accessed through ThemeProvider/useTheme. Source pixels are not runtime units; see [audit](reference-audit.md). The gallery at `/gallery` exercises variants/states with labeled local fixtures. Props listed here are the intentional contract; arbitrary feature styling is not a widget API.

## Shared form adapter

`FormTextField({field,label,kind,...inputProps})` accepts a TanStack field with string value/change/blur/error metadata. It maps Zod/server errors to the same native Field, intentionally sets username correction/capitalization off and password secure/autofill behavior, and preserves recoverable values. Business validation stays server-side.

Feature-specific `SongPicker`, `SongPreview` and `MusicPlaybackProvider` implement catalog search, loading/empty/error/retry, selection and actual play/pause/progress. One route-scoped player streams catalog previews; no simulated playback state. Gallery interactions change local fixture state only and are labeled accordingly. No social counts, endpoint writes, paid AI calls or unsupported publishing actions are simulated as finished product behavior.

`AuthFrame` lives beside auth and provides its wordmark, scalable hero, keyboard-aware spacing, optional Back and bottom actions. `AppShell` owns authenticated Home/Friends routing, the query field, real profile avatar and center Add sheet; it stays feature-specific. Hero typography and navigation dimensions are generated semantic tokens. Gallery identity examples include the quiet field composition and password state.

The memory feature composes `MemoryHeader`, `MemoryPhoto`, its collector/editor, `MemoryCanvas` and sharing screens. `IconButton` supports a primary variant for the editor’s white circular Done. `ThemeProvider appearance="editor"` applies only the tokenized backstory palette. The development gallery includes the scoped dark quote/field controls. Public memory rendering uses an escaped, read-only HTML adaptation; it does not import reference assets.

`MemoryCanvas` uses `appearance="memory"`, a square viewport, full-bleed photo/story placement, world-anchored radial halos and boundary-aware directional fog. `SongPreview` displays contributor attribution separately from the catalog artist. The gallery includes a labeled static dark ambient-color fixture with no track or audio loaded. Its original spatial cards remain illustrative fixtures rather than a rendering of the live geometry algorithm.
